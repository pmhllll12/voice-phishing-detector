# 통과하고, 실전 첫 transcribe() 호출에서야 "Library libcublas.so.12 is not found"로
# 실패한다(이 환경 — WSL2 + RTX 3050 — 에서 직접 재현/확인함). 그래서 이 pip 패키지들로
# cuBLAS/cuDNN을 받고, 아래 두 디렉터리를 LD_LIBRARY_PATH에 추가해야 한다
# (Dockerfile 참고. 로컬에서 uvicorn을 직접 띄울 때도 동일하게 필요 — README
# "rag-worker 로컬 실행" 절과 달리 이쪽은 pip install만으로는 부족하다):
#   $(python -c "import os,nvidia.cublas,nvidia.cudnn;print(os.path.dirname(nvidia.cublas.__file__)+'/lib')")
#   $(python -c "import os,nvidia.cudnn;print(os.path.dirname(nvidia.cudnn.__file__)+'/lib')")
# 이 라이브러리들 없이 GPU 로드/워밍업이 실패해도 서비스가 죽지는 않는다 —
