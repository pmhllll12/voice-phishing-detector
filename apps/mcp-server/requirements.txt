# F-01/F-02 v2는 Ollama를 별도 프로세스로 띄워두고 HTTP(/api/generate)로만 통신한다
# (ollama_call_analysis_adapter.py 참고) — 이 requirements.txt에 ollama 관련 pip
# 패키지는 필요 없다. Ollama 자체는 https://ollama.com/download 로 별도 설치하고,
# `OLLAMA_MODEL`(기본값 exaone3.5:2.4b-instruct-q4_K_M) 모델을 pull해둬야 한다:
#   ollama pull exaone3.5:2.4b-instruct-q4_K_M
# Ollama가 안 떠 있거나 모델이 없으면 키워드 규칙 기반(v1)으로 자동 폴백한다.
