# 제안요청서 (RFP)

**사업명**: AI 기반 보이스피싱 실시간 탐지 및 대응 시스템 구축
**발주처(가상)**: 금융감독원 산하 금융사기대응센터
**문서 성격**: 개인 포트폴리오 프로젝트를 위한 가상 시뮬레이션 문서 (실제 발주 문서 아님)

> 이 문서는 공공/금융 SI 프로젝트의 요구사항정의 프로세스를 1인이 엔드투엔드로 시뮬레이션하기 위해
> 작성된 가상 RFP입니다. 실제 금융감독원, 금융사기대응센터와 무관합니다.

---

## 1. 사업 개요

### 1.1 사업 목적
전화·문자 기반 보이스피싱 피해를 예방하기 위해, 통화/문자 내용을 실시간으로 분석하여
사기 패턴을 탐지하고, 딥보이스(AI 합성 음성) 여부를 판별하며, 유사 사기사례를 근거로 제시하여
탐지 결과의 신뢰성과 설명가능성을 확보하는 AI 시스템을 구축한다.

### 1.2 주요 기능 범위
1. 통화/문자 텍스트 기반 보이스피싱 패턴 탐지 에이전트
2. 음성 딥페이크(딥보이스) 판별 모듈
3. RAG 기반 유사 사기사례 매칭 (판정 근거 설명가능성 확보)
4. MCP 서버를 통한 도구 분리 (통화분석 / 사기패턴DB조회 / 신고연동)
5. 관제 대시보드 (탐지 현황, 위험도 분포, 처리 통계)
6. 감사증적(Audit Trail) — 모든 AI 판정 과정 로그 기록

## 2. 기능 요구사항 (Functional Requirements)

| ID | 요구사항명 | 설명 |
|----|-----------|------|
| F-01 | 통화 텍스트 분석 | 공포조성, 기관사칭(검찰/금감원 등), 긴급송금유도 등 보이스피싱 특징 패턴을 탐지한다 |
| F-02 | 위험도 스코어링 | 0~100점 스코어를 산출하고, 저/중/고 3단계 등급으로 분류한다 |
| F-03 | 딥보이스 판별 | 통화 음성이 AI 합성 음성인지 여부를 판별한다 |
| F-04 | 유사사례 매칭 | RAG 기반으로 기존 사기유형 DB에서 유사 사례를 검색한다 |
| F-05 | 판정 근거 제시 | 왜 보이스피싱으로 판단했는지 자연어로 설명을 제공한다 (블랙박스 판정 금지) |
| F-06 | 관제 대시보드 | 실시간 탐지 현황과 통계를 시각화한다 |
| F-07 | 신고 연동 | 고위험 판정 시 알림을 발송하고 신고 접수 프로세스를 개시한다 |

## 3. 비기능 요구사항 (Non-Functional Requirements)

| ID | 요구사항명 | 설명 |
|----|-----------|------|
| N-01 | 감사증적 | 모든 판정 과정을 변경 불가능한(append-only) 로그로 기록한다 |
| N-02 | 접근통제 | RBAC 기반으로 조회/처리/관리자 권한을 분리한다 |
| N-03 | 개인정보 비식별화 | 통화 내용 중 개인정보(이름, 계좌번호, 전화번호 등)를 마스킹한다 |
| N-04 | 설명가능성 | 모든 판정에 추적 가능한 근거를 제공한다 (블랙박스 판정 불가) |
| N-05 | 응답시간 | 통화 종료 후 평균 5초 이내에 판정 결과를 산출한다 |
| N-06 | 확장성 | 신규 사기유형 추가 시 시스템 재설계 없이 확장 가능한 구조로 설계한다 |

## 4. 데이터 관련 제약사항

- 실제 보이스피싱 통화 녹음 데이터는 사용할 수 없다.
- 공개된 뉴스, 경찰청 공개자료, 시나리오 기반의 **합성 데이터셋을 직접 제작**하여 사용한다.
- 딥보이스 판별 모델은 자체 개발 또는 검증된 오픈소스 모델 활용 모두 허용한다.
  핵심 평가 기준은 "모델을 직접 만드는 것"이 아니라 **"판별 근거를 해석 가능한 형태로 제공하는 것"**이다.

## 6. 평가 기준 (포트폴리오 셀프 체크리스트)
