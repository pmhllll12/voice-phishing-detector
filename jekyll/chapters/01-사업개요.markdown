## 1) 추진 배경

보이스피싱은 전화·문자를 통해 검찰·금융감독원 등 공신력 있는 기관을 사칭하거나, 공포를
조성해 피해자를 심리적으로 압박한 뒤 긴급 송금을 유도하는 방식으로 이뤄진다. 최근에는
AI 합성 음성(딥보이스)을 이용해 지인이나 가족의 목소리를 흉내 내는 신종 수법까지 등장하면서,
기존의 키워드 차단이나 사후 신고 중심 대응만으로는 피해를 막기 어려워지고 있다.

이 프로젝트는 이런 배경에서 **AI 데이터센터/AI 인프라 엔지니어 직무 취업을 위한 개인
포트폴리오**로 기획됐다. 실제 발주 프로젝트가 아니라, 공공/금융 SI 프로젝트가 밟는
"제안서 → 요구사항정의서/설계서 → 구현 → 시험(검수)계획서" 전 과정을 **1인이
엔드투엔드로 시뮬레이션**하기 위해 가상의 RFP(`docs/RFP.md`)를 스스로 작성하고, 그
요구사항을 실제로 구현·검증해나가는 방식으로 진행한다(`docs/RFP.md` 참고).

## 2) 사업 목적

전화·문자 기반 보이스피싱 피해를 예방하기 위해, 통화/문자 내용을 실시간으로 분석하여
사기 패턴을 탐지하고, 딥보이스(AI 합성 음성) 여부를 판별하며, 유사 사기사례를 근거로
제시하여 탐지 결과의 신뢰성과 설명가능성을 확보하는 AI 시스템을 구축한다.

이 프로젝트의 핵심 차별점은 **"블랙박스 판정 불가"**다. 위험도 점수만 뱉는 시스템이
아니라, 왜 그렇게 판단했는지를 매 판정마다 사람이 검증할 수 있는 형태(탐지된 패턴,
자연어 설명, 유사 사기사례)로 함께 반환하도록 설계했다(N-04, `CLAUDE.md` 참고).

## 3) 사업 범위

| # | 범위 | 비고 |
|---|---|---|
| 1 | 통화/문자 텍스트 기반 보이스피싱 패턴 탐지 에이전트 | F-01 |
| 2 | 음성 딥페이크(딥보이스) 판별 모듈 | F-03 |
| 3 | RAG 기반 유사 사기사례 매칭 (판정 근거 설명가능성 확보) | F-04, N-04 |
| 4 | MCP 서버를 통한 도구 분리 (통화분석 / 사기패턴DB조회 / 신고연동) | F-01, F-04, F-07 |
| 5 | 관제 대시보드 (탐지 현황, 위험도 분포, 처리 통계) | F-06 |
| 6 | 감사증적(Audit Trail) — 모든 AI 판정 과정 로그 기록 | N-01 |

**범위에서 명시적으로 제외한 것**: 실제 보이스피싱 통화 녹음은 사용하지 않는다. 뉴스·
경찰청 공개자료를 바탕으로 직접 제작한 합성 시나리오 데이터셋만 사용하며(`docs/RFP.md`
4장), 실제 112/경찰청 신고 API 연동도 하지 않는다(F-07은 mock 처리 — `docs/RFP.md`
4장, 개발 구현 계획의 F-07 절 참고). 딥보이스 판별도 "정확도 최고 수준의 모델을 직접
만드는 것"이 목표가 아니라 **"판별 근거를 해석 가능한 형태로 제공하는 것"**이 평가
기준이다.
